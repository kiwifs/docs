[KiwiFS Cloud](https://app.kiwifs.com) is the hosted version of KiwiFS. It runs the server, backups, TLS, and sign-in for you, so you can skip deployment. Each workspace is a KiwiFS knowledge base with the same MCP tools as a self-hosted server.

This page covers connecting to a Cloud workspace from your agents and the `kiwifs` CLI. For self-hosting, start with the [Quickstart](/quickstart).

## Connect an MCP client

Each workspace has an MCP endpoint:

```text
https://api.kiwifs.com/api/workspaces/{slug}/mcp
```

Authenticate with your workspace API key, which you find in the workspace settings at [app.kiwifs.com](https://app.kiwifs.com).

<Tabs>
  <Tab title="CLI (recommended)">
    `kiwifs connect` prints a ready-to-paste config, or writes it into your client's config file:

    ```bash Terminal
    export KIWI_API_KEY=kiwi_sk_...
    kiwifs connect my-workspace                  # print config
    kiwifs connect my-workspace --write cursor   # write to Cursor
    kiwifs connect my-workspace --write auto     # write to every detected client
    ```

    Restart the client afterwards.
  </Tab>
  <Tab title="URL clients">
    For clients that support remote MCP servers (Cursor, Claude Code, Windsurf, VS Code, and others):

    ```json mcp.json
    {
      "mcpServers": {
        "kiwi": {
          "url": "https://api.kiwifs.com/api/workspaces/my-workspace/mcp",
          "headers": { "Authorization": "Bearer ${env:KIWI_API_KEY}" }
        }
      }
    }
    ```
  </Tab>
  <Tab title="Claude Desktop">
    Claude Desktop runs MCP servers over stdio, so bridge to the workspace with `kiwifs mcp --remote`:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "kiwi": {
          "command": "kiwifs",
          "args": [
            "mcp",
            "--remote", "https://api.kiwifs.com/api/workspaces/my-workspace",
            "--api-key", "kiwi_sk_..."
          ]
        }
      }
    }
    ```
  </Tab>
</Tabs>

<Warning>
Treat the API key like a password. `kiwifs connect` without `--write` prints a config that reads the key from `KIWI_API_KEY`, which is safe to commit. `--write` embeds the key in the client's config file.
</Warning>

## kiwifs connect

```bash
kiwifs connect <workspace-slug> [flags]
```

<AccordionGroup>
  <Accordion title="Flags">
    | Flag | Default | Description |
    | --- | --- | --- |
    | `--key` | `KIWI_API_KEY` | Workspace API key. If unset, the CLI uses your `kiwifs login` session to fetch it. |
    | `--write` | — | Write the config to `cursor`, `claude-code`, `windsurf`, `claude-desktop`, or `auto` (every detected client) |
    | `--project` | `false` | Write to the project config (`.cursor/mcp.json` or `.mcp.json`) instead of the global one |
    | `--host` | `https://api.kiwifs.com` | API host |
  </Accordion>
  <Accordion title="Config files it writes">
    | Client | Global config | Project config |
    | --- | --- | --- |
    | `cursor` | `~/.cursor/mcp.json` | `.cursor/mcp.json` |
    | `claude-code` | `~/.claude/settings.json` | `.mcp.json` |
    | `windsurf` | `~/.codeium/windsurf/mcp_config.json` | — |
    | `claude-desktop` | `claude_desktop_config.json` in the Claude app folder | — |

    Existing entries in those files are kept; only the `kiwi` server entry is added or replaced.
  </Accordion>
</AccordionGroup>

## Sign in from the CLI

`kiwifs login` uses the OAuth device flow: the CLI shows a code, you confirm it in your browser, and the CLI stores a session in `~/.kiwifs/credentials.json`. After that, `kiwifs connect` works without `--key`.

```bash Terminal
kiwifs login     # sign in through your browser
kiwifs whoami    # show the signed-in account
kiwifs logout    # remove stored credentials
```

## Cloud and self-hosted compared

| | Self-hosted | Cloud |
| --- | --- | --- |
| Runs on | Your machine, Docker, or Kubernetes | Managed by KiwiFS |
| Auth | `none`, `apikey`, `perspace`, or `oidc` | Workspace API key or browser sign-in |
| MCP endpoint | `http://host:3333/mcp`, or `kiwifs mcp` over stdio | `https://api.kiwifs.com/api/workspaces/{slug}/mcp` |
| NFS, S3, WebDAV | Available with `kiwifs serve` flags | Not available |
| Workspaces | One server, one or more [spaces](/concepts/multi-space) | One workspace per slug |
