KiwiFS stores **real files** on disk. POSIX behavior depends on **how** you access them.

## Compliance by access path

| Access path | POSIX level | Notes |
| --- | --- | --- |
| **Direct filesystem** | Full | Real files, atomic writes, mmap works |
| **NFS mount** | Near-full | Symlinks, open-unlink, stable handles |
| **FUSE mount** | Near-full | Remote client; no kernel mmap |
| **WebDAV** | Partial | MOVE/COPY/MKCOL; buffered writes |
| **REST API** | N/A | ETag concurrency, not POSIX |
| **S3 API** | N/A | S3 semantics |
| **MCP** | N/A | Tool calls |

## What works on NFS and FUSE

| Semantic | NFS | FUSE |
| --- | --- | --- |
| Atomic writes | Yes | Yes |
| `rename` | Yes | Yes |
| Symlinks | Yes | Yes |
| Open-then-delete | Yes (NFS) | — |
| `fsync` | Yes | Yes |
| Directory rename | Yes | Yes |
| `readdir` hides `.git`, `.kiwi` | Yes | Yes |
| 64MB max file size (`EFBIG`) | Yes | Yes |

## Concurrency and durability

- **Optimistic locking** — `If-Match` / ETag on REST writes; `409` on conflict.
- **Serialized writes** — one mutex across protocols.
- **Single-instance guard** — `flock` on `.kiwi/server.lock`; released on process exit.
- **Git lock recovery** — stale `index.lock` cleaned on a timer and at startup.
- **Line endings** — `core.autocrlf=false` and `* -text` in `.gitattributes` keep ETags aligned with raw bytes.

## Intentionally limited

- FUSE does not support kernel **mmap** (HTTP-backed I/O).
- WebDAV is not a full POSIX layer.
- Two KiwiFS servers must not share one knowledge root — the lock prevents split-brain.

## Symlinks

Symlinks work on NFS (real `os.Symlink`) and FUSE/REST (`Content-Type: application/x-symlink`). Targets that escape the knowledge root are rejected.

```bash
curl 'http://localhost:3333/api/kiwi/readlink?path=link.md'
```
