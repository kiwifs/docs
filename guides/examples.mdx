## Agent memory knowledge base

Start from the `memory` template and let agents read the playbook on connect:

```bash Terminal
kiwifs init --template memory --root ./knowledge
kiwifs serve --root ./knowledge
```

## Agent writes

<AccordionGroup>
  <Accordion title="REST: write one file with provenance">
    ```bash Terminal
    curl -X PUT 'http://localhost:3333/api/kiwi/file?path=pages/auth.md' \
      -H 'X-Actor: my-agent' \
      -H 'X-Provenance: run:run-249' \
      --data-binary $'# Authentication\n\nOAuth2 + JWT.'
    ```

    `X-Provenance` adds a `derived-from` entry to the page's frontmatter.
  </Accordion>

  <Accordion title="REST: write several files in one commit">
    ```bash Terminal
    curl -X POST 'http://localhost:3333/api/kiwi/bulk' \
      -H 'Content-Type: application/json' \
      -d '{
        "files": [
          {"path": "pages/auth.md", "content": "# Auth\n\nUpdated."},
          {"path": "pages/sessions.md", "content": "# Sessions\n\nNew."}
        ],
        "actor": "agent:exec_abc",
        "message": "run 249"
      }'
    ```
  </Accordion>

  <Accordion title="REST: append to a log">
    ```bash Terminal
    curl -X POST 'http://localhost:3333/api/kiwi/file/append?path=log.md' \
      -H 'X-Actor: my-agent' \
      --data-binary $'\n- 2026-10-19: updated auth'
    ```
  </Accordion>

  <Accordion title="Filesystem mount">
    ```bash Terminal
    echo "# Finding" > /mnt/kiwi/pages/finding-042.md
    ```

    See [Alternate protocols](/guides/alternate-protocols).
  </Accordion>

  <Accordion title="Find everything one run produced">
    ```bash Terminal
    curl 'http://localhost:3333/api/kiwi/meta?where=$.derived-from[*].id=run-249'
    ```
  </Accordion>
</AccordionGroup>

## MCP tool sequences

<AccordionGroup>
  <Accordion title="First connection">
    ```text
    kiwi_context
    ```
  </Accordion>

  <Accordion title="Ingest a source">
    ```text
    kiwi_search("authentication")
    kiwi_write("pages/auth.md", content)
    kiwi_read("index.md")
    kiwi_write("index.md", updated)
    kiwi_append("log.md", "- added auth")
    ```
  </Accordion>

  <Accordion title="Answer a question">
    ```text
    kiwi_search("payment timeout")
    kiwi_read("pages/payments.md")
    ```
  </Accordion>

  <Accordion title="Remember and consolidate">
    ```text
    kiwi_remember(observation)            # writes episodes/{date}/{id}.md
    kiwi_memory_report                    # episodes not yet merged
    kiwi_write("pages/topic.md", merged_content_with_merged_from)
    kiwi_forget("episodes/2026-10-19/abc.md")
    ```

    See [Episodic memory](/concepts/episodic-memory).
  </Accordion>

  <Accordion title="Write a widget or quiz">
    ```text
    kiwi_widget_reference("tree")         # syntax for a widget fence
    kiwi_quiz(...)                        # format a Kiwi Quiz callout
    kiwi_write("lessons/heaps.md", content)
    kiwi_lint("lessons/heaps.md")
    ```

    See [Widgets](/concepts/widgets).
  </Accordion>

  <Accordion title="Restructure safely">
    ```text
    kiwi_refactor_plan(manifest)          # preview, nothing written
    kiwi_refactor_apply(manifest, digest) # one commit
    kiwi_refactor_revert(commit)          # undo if needed
    ```

    Some plans need a person to approve them in the web UI first. See [Refactor](/concepts/refactor).
  </Accordion>

  <Accordion title="Health check">
    ```text
    kiwi_analytics
    kiwi_health_check("pages/auth.md")
    kiwi_lint
    ```
  </Accordion>
</AccordionGroup>

## Query with DQL

<CodeGroup>
```bash Table
kiwifs query 'TABLE title, status FROM "pages" WHERE status = "draft" SORT priority DESC'
```

```bash Count by group
kiwifs query 'COUNT FROM "pages" GROUP BY status'
```

```bash Aggregate
kiwifs aggregate --group status --calc count,avg:priority
```

```bash REST
curl -G 'http://localhost:3333/api/kiwi/query' \
  --data-urlencode 'q=TABLE title FROM "pages"'
```
</CodeGroup>

See [DQL](/concepts/dql).

## Move pages without breaking links

Write a manifest, preview it, then apply it as one commit:

```yaml restructure.yaml
moves:
  - from: notes/*-meeting.md
    to: meetings/
merges:
  - from: faq/duplicate.md
    into: faq/canonical.md
rename_tags:
  - {from: ml, to: machine-learning}
delete_empty_dirs: true
```

```bash Terminal
kiwifs refactor plan restructure.yaml --root ./knowledge
kiwifs refactor apply restructure.yaml --root ./knowledge
kiwifs refactor revert <commit> --root ./knowledge   # undo
```

Every link to a moved page is rewritten in the style it was written in. See [Refactor](/concepts/refactor).

## Import

<CodeGroup>
```bash PostgreSQL
kiwifs import --from postgres --dsn "postgres://user:pass@host/db" --table users --root ./knowledge
```

```bash Obsidian
kiwifs import --from obsidian --path ~/vault --root ./knowledge
```

```bash Notion
export NOTION_API_KEY=secret_...
kiwifs import --from notion --database-id abc123 --root ./knowledge
```

```bash CSV dry run
kiwifs import --from csv --file data.csv --root ./knowledge --dry-run
```
</CodeGroup>

See [Import overview](/import/overview).

## Export

<CodeGroup>
```bash JSONL with content
kiwifs export --format jsonl --include-content -o knowledge.jsonl
```

```bash With embeddings
kiwifs export --format jsonl --include-embeddings -o vectors.jsonl
```

```bash PDF (server-side)
curl -X POST 'http://localhost:3333/api/kiwi/export/document' \
  -H 'Content-Type: application/json' \
  -d '{"format":"pdf","path":"pages/report.md"}' -o report.pdf
```
</CodeGroup>

See [Document export](/export/documents).

## Production config

```toml .kiwi/config.toml
[server]
public_url = "https://wiki.example.com"

[auth]
type = "apikey"
api_key = "${KIWI_API_KEY}"

[search.vector]
enabled = true

[search.vector.embedder]
provider = "ollama"
model = "nomic-embed-text"

[search.vector.store]
provider = "sqlite"

[backup]
remote = "git@github.com:org/knowledge.git"
interval = "5m"
```

See [Configuration](/configuration) and [Authentication](/guides/auth-tokens).

## Go embed

```go main.go
import "github.com/kiwifs/kiwifs/pkg/kiwi"

srv, err := kiwi.New("/data/knowledge", kiwi.WithSearch("sqlite"))
if err != nil {
    log.Fatal(err)
}
mux.Handle("/wiki/", http.StripPrefix("/wiki", srv.Handler()))
```
