A draft is a git branch with its own worktree. An agent can write a batch of changes there, you review the diff, and then merge it into main in one fast-forward or throw it away. Main stays untouched until the merge.

Drafts are off by default. Turn them on in `.kiwi/config.toml`:

```toml .kiwi/config.toml
[drafts]
enabled = true
max_active = 10   # default 10
```

When drafts are off, every endpoint on this page returns `501`. All paths are relative to `http://localhost:3333/api/kiwi`. See [Draft spaces](/concepts/draft-spaces) for the workflow.

## Create a draft

Branches from the current `HEAD` and returns the new draft.

**`POST /drafts`**

<ParamField body="actor" type="string">
  Who owns the draft. Falls back to `X-Actor`, then `api`.
</ParamField>

```bash
curl -X POST 'http://localhost:3333/api/kiwi/drafts' \
  -H "Content-Type: application/json" \
  -d '{"actor": "agent:planner"}'
```

<ResponseField name="id" type="string">Eight-character hex ID used in every other draft route.</ResponseField>
<ResponseField name="branch" type="string">Git branch, `draft/{id}`.</ResponseField>
<ResponseField name="actor" type="string">Owner.</ResponseField>
<ResponseField name="created_at" type="string">Creation time (RFC 3339).</ResponseField>

```json 201 Created
{
  "id": "3fa9c21e",
  "branch": "draft/3fa9c21e",
  "actor": "agent:planner",
  "created_at": "2026-10-19T09:30:00Z"
}
```

Returns `409` when `max_active` drafts already exist or the repository has no commits yet.

## List drafts

Returns all active drafts as an array of the same objects.

**`GET /drafts`**

```bash
curl 'http://localhost:3333/api/kiwi/drafts'
```

```json Response
[
  {"id": "3fa9c21e", "branch": "draft/3fa9c21e", "actor": "agent:planner", "created_at": "2026-10-19T09:30:00Z"}
]
```

## Get a draft

Returns one draft.

**`GET /drafts/:id`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/drafts/3fa9c21e'
```

Returns the draft object, or `404` if the ID is unknown.

## Read a file in a draft

Returns a file's content as it is in the draft, with an `ETag` header.

**`GET /drafts/:id/file`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>
<ParamField query="path" type="string" required>
  File path.
</ParamField>

```bash
curl -i 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/file?path=concepts/auth.md'
```

The body is `text/markdown`. Returns `404` if the draft or file does not exist.

## Write a file in a draft

Creates or replaces a file on the draft branch. The body is the full file content.

**`PUT /drafts/:id/file`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>
<ParamField query="path" type="string" required>
  File path.
</ParamField>
<ParamField header="X-Actor" type="string" default="draft-api">
  Commit author on the draft branch.
</ParamField>

```bash
curl -X PUT 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/file?path=concepts/auth.md' \
  -H "X-Actor: agent:planner" \
  --data-binary @auth.md
```

```json Response
{"path": "concepts/auth.md", "etag": "c3d4e5f6..."}
```

<Note>
Draft writes do not check `If-Match`. The merge is a plain git fast-forward, so review the diff before you merge.
</Note>

## Delete a file in a draft

Deletes a file on the draft branch.

**`DELETE /drafts/:id/file`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>
<ParamField query="path" type="string" required>
  File path.
</ParamField>
<ParamField header="X-Actor" type="string" default="draft-api">
  Commit author.
</ParamField>

```bash
curl -X DELETE 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/file?path=concepts/old.md'
```

Returns `204` with no body.

## Get a draft's tree

Returns the draft's folder hierarchy, in the same shape as [`GET /tree`](/api/files#get-the-directory-tree).

**`GET /drafts/:id/tree`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>
<ParamField query="path" type="string" default="/">
  Folder to start from.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/tree'
```

## Diff a draft

Returns everything the draft changed since it branched from main, as a unified diff.

**`GET /drafts/:id/diff`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/diff'
```

```json Response
{"diff": "diff --git a/concepts/auth.md b/concepts/auth.md\n--- a/concepts/auth.md\n+++ b/concepts/auth.md\n@@ -1,3 +1,3 @@\n..."}
```

## Merge a draft

Fast-forwards main to the draft branch, then removes the draft. Uncommitted files in the draft worktree are committed first.

**`POST /drafts/:id/merge`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>

```bash
curl -X POST 'http://localhost:3333/api/kiwi/drafts/3fa9c21e/merge'
```

```json Response
{"status": "merged"}
```

Returns `409` when main has moved since the draft was created, because only fast-forward merges are allowed. Recreate the draft from the new `HEAD`, or apply the changes to main directly.

## Discard a draft

Deletes the draft's branch and worktree. Main is unchanged.

**`DELETE /drafts/:id`**

<ParamField path="id" type="string" required>
  Draft ID.
</ParamField>

```bash
curl -X DELETE 'http://localhost:3333/api/kiwi/drafts/3fa9c21e'
```

Returns `204` with no body, or `404` if the ID is unknown.
