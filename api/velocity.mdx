These endpoints help you understand the shape of a knowledge base: which pages churn, which are central, how pages connect, which pages are related but not linked, and how well search finds the right page.

| Endpoint | Needs |
| --- | --- |
| Velocity | Git versioning |
| Graph endpoints | The link index (on by default). `503` when unavailable. |
| Suggestions, embeddings | Vector search. `503` when it is off. |
| Similar | A `[[similarity.profiles]]` block in config. `503` without one. |

## Change velocity

Analyze git history for a period: which pages change most, which don't change at all, which are suddenly busy, and which have a single author.

```http
GET /api/kiwi/velocity
```

<ParamField query="period" type="string" default="30d">
  Window as a number followed by `d` (days), `w` (weeks), or `m` (months, counted as 30 days).
</ParamField>
<ParamField query="limit" type="integer" default="20">
  Maximum entries in `hot_spots`.
</ParamField>
<ParamField query="path_prefix" type="string">
  Only analyze pages under this prefix.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/velocity?period=2w&limit=5'
```

Only markdown files are counted. Returns `500` if `git log` fails, for example when versioning is off.

<ResponseField name="period" type="string">Period used.</ResponseField>
<ResponseField name="total_changes" type="integer">File changes (one per commit per file) in the period.</ResponseField>
<ResponseField name="hot_spots" type="object[]">
  Most changed pages, descending.
  <Expandable title="properties">
    <ResponseField name="path" type="string">Page path.</ResponseField>
    <ResponseField name="changes" type="integer">Commits touching the page.</ResponseField>
    <ResponseField name="authors" type="integer">Distinct commit authors.</ResponseField>
    <ResponseField name="lines_changed" type="integer">Lines added plus lines deleted.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="cold_spots" type="object[]">
  Every page with no changes in the period, each with `path` and `days_since_change`.
</ResponseField>
<ResponseField name="bursts" type="object[]">
  Pages whose change rate over the last 7 days is more than three times their average for the period.
  <Expandable title="properties">
    <ResponseField name="path" type="string">Page path.</ResponseField>
    <ResponseField name="recent_rate" type="number">Changes per day over the last 7 days.</ResponseField>
    <ResponseField name="avg_rate" type="number">Changes per day over the whole period.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="single_author_pages" type="string[]">Pages changed in the period by only one author.</ResponseField>

```json
{
  "period": "2w",
  "total_changes": 87,
  "hot_spots": [
    { "path": "concepts/auth.md", "changes": 12, "authors": 3, "lines_changed": 240 }
  ],
  "cold_spots": [
    { "path": "concepts/legacy.md", "days_since_change": 120 }
  ],
  "bursts": [
    { "path": "runbooks/deploy.md", "recent_rate": 1.29, "avg_rate": 0.36 }
  ],
  "single_author_pages": ["runbooks/deploy.md"]
}
```

## Graph analytics

Summarize the wiki link graph: size, connected components, orphans, and the highest PageRank pages.

```http
GET /api/kiwi/graph/analytics
```

<ParamField query="limit" type="integer" default="20">
  Number of pages in `top_pages`.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/graph/analytics?limit=10'
```

<ResponseField name="total_nodes" type="integer">Pages in the link graph.</ResponseField>
<ResponseField name="total_edges" type="integer">Wiki links.</ResponseField>
<ResponseField name="components" type="integer">Disconnected subgraphs.</ResponseField>
<ResponseField name="largest_component_size" type="integer">Pages in the largest component.</ResponseField>
<ResponseField name="orphans" type="string[]">Pages with no incoming links.</ResponseField>
<ResponseField name="top_pages" type="object[]">Highest PageRank pages, each with `path`, `pagerank`, `in_degree`, and `out_degree`.</ResponseField>

```json
{
  "total_nodes": 142,
  "total_edges": 387,
  "components": 3,
  "largest_component_size": 138,
  "orphans": ["concepts/legacy.md"],
  "top_pages": [
    { "path": "concepts/auth.md", "pagerank": 0.042, "in_degree": 18, "out_degree": 5 }
  ]
}
```

## Centrality

Return PageRank, betweenness, and degree for every page, highest PageRank first.

```http
GET /api/kiwi/graph/centrality
```

<ParamField query="limit" type="integer">
  Maximum pages. Omit to return all.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/graph/centrality?limit=20'
```

<ResponseField name="pages" type="object[]">
  <Expandable title="properties">
    <ResponseField name="path" type="string">Page path.</ResponseField>
    <ResponseField name="pagerank" type="number">PageRank score.</ResponseField>
    <ResponseField name="betweenness" type="number">How often the page sits on shortest paths between other pages.</ResponseField>
    <ResponseField name="in_degree" type="integer">Incoming links.</ResponseField>
    <ResponseField name="out_degree" type="integer">Outgoing links.</ResponseField>
  </Expandable>
</ResponseField>

```json
{
  "pages": [
    { "path": "concepts/auth.md", "pagerank": 0.042, "betweenness": 0.18, "in_degree": 18, "out_degree": 5 }
  ]
}
```

## Communities

Group pages into topic clusters with Louvain community detection. Links are treated as undirected.

```http
GET /api/kiwi/graph/communities
```

```bash
curl 'http://localhost:3333/api/kiwi/graph/communities'
```

<ResponseField name="communities" type="object[]">Clusters, each with a numeric `id` and its `pages`.</ResponseField>

```json
{
  "communities": [
    { "id": 0, "pages": ["concepts/auth.md", "concepts/sessions.md", "runbooks/login-flow.md"] },
    { "id": 1, "pages": ["concepts/billing.md", "concepts/invoices.md"] }
  ]
}
```

## Shortest path

Return the shortest chain of wiki links from one page to another, following link direction.

```http
GET /api/kiwi/graph/path
```

<ParamField query="from" type="string" required>
  Start page.
</ParamField>
<ParamField query="to" type="string" required>
  End page.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/graph/path?from=concepts/auth.md&to=concepts/billing.md'
```

Returns `400` if either parameter is missing, and `404` if a page isn't in the graph or no path exists.

<ResponseField name="path" type="string[]">Pages from `from` to `to`, inclusive.</ResponseField>

```json
{ "path": ["concepts/auth.md", "concepts/users.md", "concepts/billing.md"] }
```

## Graph walk

Return one page's immediate neighborhood: outgoing links, backlinks, and pages in the same folder or with a shared tag.

```http
GET /api/kiwi/graph/walk
```

<ParamField query="path" type="string" required>
  Page path.
</ParamField>
<ParamField query="include_siblings" type="boolean" default="true">
  Set to `false` to skip folder and tag siblings, which requires scanning every page.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/graph/walk?path=concepts/auth.md'
```

Returns `404` if the page does not exist.

<ResponseField name="path" type="string">Page path.</ResponseField>
<ResponseField name="links_out" type="string[]">Wiki link targets in the page, as written.</ResponseField>
<ResponseField name="links_in" type="string[]">Pages that link here.</ResponseField>
<ResponseField name="siblings" type="object[]">
  Each with `path`, `relation` (`sibling_dir` or `sibling_tag`), and `shared_tag` for tag siblings.
</ResponseField>
<ResponseField name="hub_score" type="number">Incoming links divided by pages in the graph.</ResponseField>
<ResponseField name="in_degree" type="integer">Length of `links_in`.</ResponseField>
<ResponseField name="out_degree" type="integer">Length of `links_out`.</ResponseField>

```json
{
  "path": "concepts/auth.md",
  "links_out": ["sessions", "api-keys"],
  "links_in": ["index.md", "runbooks/login-flow.md"],
  "siblings": [
    { "path": "concepts/sessions.md", "relation": "sibling_dir" },
    { "path": "runbooks/login-flow.md", "relation": "sibling_tag", "shared_tag": "security" }
  ],
  "hub_score": 0.014,
  "in_degree": 2,
  "out_degree": 2
}
```

## Link suggestions

Find pages that are semantically close to a page but not yet linked to or from it. Use this to discover missing wiki links.

```http
GET /api/kiwi/suggestions
```

<ParamField query="path" type="string" required>
  Page path.
</ParamField>
<ParamField query="limit" type="integer" default="10">
  Maximum suggestions.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/suggestions?path=concepts/auth.md&limit=3'
```

Returns `400` if `path` is missing, `404` if the page does not exist, and `503` if vector search is off. `suggestions` is `null` when nothing qualifies.

<ResponseField name="suggestions" type="object[]">
  <Expandable title="properties">
    <ResponseField name="target" type="string">Suggested page.</ResponseField>
    <ResponseField name="similarity" type="number">Vector similarity score.</ResponseField>
    <ResponseField name="snippet" type="string">Matching text from the suggested page.</ResponseField>
  </Expandable>
</ResponseField>

```json
{
  "suggestions": [
    { "target": "concepts/api-keys.md", "similarity": 0.89, "snippet": "API key authentication..." }
  ]
}
```

## Similar pages

Rank pages by how similar their frontmatter is, using Gower distance over the fields in a similarity profile. Query by a page, or by an inline set of field values for a case that isn't in the knowledge base yet.

```toml .kiwi/config.toml
[[similarity.profiles]]
name = "dataset"
match = { kind = "dataset" }
numeric = ["stats.rows", "stats.columns"]
categorical = ["format", "license"]
weights = { "license" = 3.0 }
```

```http
GET /api/kiwi/similar
```

<ParamField query="path" type="string">
  Page to find neighbors of. Required unless `vector` is set.
</ParamField>
<ParamField query="vector" type="string">
  JSON object of field values. Combined with `path`, it overrides that page's values.
</ParamField>
<ParamField query="profile" type="string">
  Profile name. Optional when only one profile is configured.
</ParamField>
<ParamField query="k" type="integer" default="5">
  Number of neighbors.
</ParamField>

```bash
curl -G 'http://localhost:3333/api/kiwi/similar' \
  --data-urlencode 'vector={"format":"parquet","stats.rows":120000}' \
  --data-urlencode 'profile=dataset'
```

Returns `400` when neither `path` nor `vector` is given, the profile is unknown, `k` isn't a positive integer, or `vector` isn't a JSON object.

<ResponseField name="profile" type="string">Profile used.</ResponseField>
<ResponseField name="query_path" type="string">Page queried, if any.</ResponseField>
<ResponseField name="query_vector" type="object">Field values compared against.</ResponseField>
<ResponseField name="fields" type="string[]">Profile fields.</ResponseField>
<ResponseField name="candidate_count" type="integer">Pages considered.</ResponseField>
<ResponseField name="truncated" type="boolean">`true` if the candidate set hit its cap.</ResponseField>
<ResponseField name="neighbors" type="object[]">
  Most similar first.
  <Expandable title="properties">
    <ResponseField name="path" type="string">Page path.</ResponseField>
    <ResponseField name="score" type="number">Similarity from 0 to 1. Results are ordered by this.</ResponseField>
    <ResponseField name="distance" type="number">Gower distance over the fields both sides have.</ResponseField>
    <ResponseField name="rank_distance" type="number">Distance that counts missing fields as maximally different.</ResponseField>
    <ResponseField name="coverage" type="number">Weighted share of fields that could be compared.</ResponseField>
    <ResponseField name="comparable_fields" type="integer">Fields both sides had.</ResponseField>
    <ResponseField name="total_fields" type="integer">Fields in the profile.</ResponseField>
    <ResponseField name="contributions" type="object[]">Per-field `field`, `kind`, `distance`, `weight`, `skipped`, and the two values `a` and `b`.</ResponseField>
  </Expandable>
</ResponseField>

```json
{
  "profile": "dataset",
  "query_vector": { "format": "parquet", "stats.rows": 120000 },
  "fields": ["stats.rows", "stats.columns", "format", "license"],
  "candidate_count": 38,
  "neighbors": [
    {
      "path": "datasets/orders.md",
      "score": 0.81,
      "distance": 0.06,
      "rank_distance": 0.19,
      "coverage": 0.5,
      "comparable_fields": 2,
      "total_fields": 4,
      "contributions": [
        { "field": "format", "kind": "categorical", "distance": 0, "weight": 1, "skipped": false, "a": "parquet", "b": "parquet" }
      ]
    }
  ]
}
```

## Embeddings

Return the stored text chunks and embedding vectors for a page.

```http
GET /api/kiwi/embeddings
```

<ParamField query="path" type="string" required>
  Page path.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/embeddings?path=concepts/auth.md'
```

Returns `400` if `path` is missing, `404` if the page has no embeddings, and `503` if vector search is off.

<ResponseField name="path" type="string">Page path.</ResponseField>
<ResponseField name="dimensions" type="integer">Vector length.</ResponseField>
<ResponseField name="chunks" type="object[]">Each with `chunk_idx`, `text`, and `vector`.</ResponseField>

```json
{
  "path": "concepts/auth.md",
  "dimensions": 768,
  "chunks": [
    { "chunk_idx": 0, "text": "# Authentication\n\nOAuth2...", "vector": [0.012, -0.034, 0.051] }
  ]
}
```

## Search evaluation

Score full-text, semantic, and hybrid search against questions with known answers. Reports hit rate, MRR, precision, and nDCG at `top_k`. Same as `kiwifs eval`.

```http
POST /api/kiwi/eval
```

<ParamField body="set" type="string">
  Golden set name. Loads `<set>.topics` and `<set>.qrels` from `.kiwi/eval/`. Use either `set` or `queries`.
</ParamField>
<ParamField body="queries" type="object[]">
  Inline questions.
  <Expandable title="properties">
    <ParamField body="question" type="string" required>Search text.</ParamField>
    <ParamField body="expected_paths" type="string[]">Relevant pages, each graded 1.</ParamField>
    <ParamField body="grades" type="object">Map from path to graded relevance (higher is more relevant). Only nDCG uses grades.</ParamField>
  </Expandable>
</ParamField>
<ParamField body="exclude_prefix" type="string | string[]">
  Path prefixes hidden from retrieval before ranking. Use this for leave-one-out evaluation.
</ParamField>
<ParamField body="top_k" type="integer" default="5">
  Cutoff for every metric.
</ParamField>

<CodeGroup>
```bash Golden set
curl -X POST 'http://localhost:3333/api/kiwi/eval' \
  -H "Content-Type: application/json" \
  -d '{"set": "leave-one-out", "exclude_prefix": "drafts/", "top_k": 10}'
```

```bash Inline queries
curl -X POST 'http://localhost:3333/api/kiwi/eval' \
  -H "Content-Type: application/json" \
  -d '{
    "queries": [
      {"question": "how does authentication work", "expected_paths": ["concepts/auth.md"]},
      {"question": "deploy checklist", "expected_paths": ["runbooks/deploy.md"]}
    ]
  }'
```
</CodeGroup>

Returns `400` when both or neither of `set` and `queries` are given or the set can't be loaded, and `500` if every search failed.

<ResponseField name="top_k" type="integer">Cutoff used.</ResponseField>
<ResponseField name="exclude_prefix" type="string[]">Prefixes excluded, if any.</ResponseField>
<ResponseField name="fts" type="object">
  Full-text search metrics. `semantic` and `hybrid` have the same shape; `hybrid` only has data when vector search is on.
  <Expandable title="properties">
    <ResponseField name="hit_rate" type="number">Share of questions with a relevant page in the top `top_k`.</ResponseField>
    <ResponseField name="mrr" type="number">Mean reciprocal rank of the first relevant page.</ResponseField>
    <ResponseField name="precision_at_k" type="number">Mean precision in the top `top_k`.</ResponseField>
    <ResponseField name="precision_at_5" type="number" deprecated>Same value as `precision_at_k`.</ResponseField>
    <ResponseField name="ndcg" type="number">Mean nDCG at `top_k`.</ResponseField>
    <ResponseField name="queries" type="integer">Questions scored.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="semantic" type="object">Semantic search metrics.</ResponseField>
<ResponseField name="hybrid" type="object">Hybrid (reciprocal rank fusion) metrics.</ResponseField>
<ResponseField name="per_query" type="object[]">
  Per question: `question`, `relevant`, and for each engine its rank (`fts_rank`, `semantic_rank`, `hybrid_rank`; `0` means not found), hits, and nDCG.
</ResponseField>
<ResponseField name="skipped" type="object[]">Questions that couldn't be scored, each with `question` and `reason`.</ResponseField>
<ResponseField name="errors" type="integer">Failed searches.</ResponseField>

```json
{
  "top_k": 5,
  "fts": { "hit_rate": 1.0, "mrr": 0.75, "precision_at_k": 0.3, "precision_at_5": 0.3, "ndcg": 0.81, "queries": 2 },
  "semantic": { "hit_rate": 1.0, "mrr": 0.9, "precision_at_k": 0.4, "precision_at_5": 0.4, "ndcg": 0.88, "queries": 2 },
  "hybrid": { "hit_rate": 1.0, "mrr": 0.92, "precision_at_k": 0.4, "precision_at_5": 0.4, "ndcg": 0.9, "queries": 2 },
  "per_query": [
    {
      "question": "how does authentication work",
      "relevant": ["concepts/auth.md"],
      "fts_rank": 2, "semantic_rank": 1, "hybrid_rank": 1,
      "fts_hits": ["concepts/sessions.md", "concepts/auth.md"],
      "semantic_hits": ["concepts/auth.md"],
      "hybrid_hits": ["concepts/auth.md"],
      "fts_ndcg": 0.63, "semantic_ndcg": 1, "hybrid_ndcg": 1
    }
  ],
  "errors": 0
}
```
