The KiwiFS REST API gives you read and write access to a markdown filesystem over HTTP. Everything the web UI does goes through these endpoints, and most MCP tools have a REST equivalent.

## Base URL

```text
http://localhost:3333/api/kiwi
```

Every knowledge endpoint lives under `/api/kiwi/`. Health, metrics, OpenAPI, raw files, `llms.txt`, and MCP sit at the server root.

### Selecting a space

A server can host several spaces. Pick one in either of two ways:

<CodeGroup>
```bash Path segment
curl 'http://localhost:3333/api/kiwi/engineering/file?path=concepts/auth.md'
```

```bash X-Kiwi-Space header
curl 'http://localhost:3333/api/kiwi/file?path=concepts/auth.md' \
  -H "X-Kiwi-Space: engineering"
```
</CodeGroup>

The header takes precedence over the path. An unknown name in `X-Kiwi-Space` returns `404` instead of falling back to another space. Requests with neither go to the primary space. Space administration (`/api/spaces`) is covered in [Spaces admin](/api/spaces).

## Authentication

Set the mode with `[auth] type` in `.kiwi/config.toml`. Every mode except `none` expects an `Authorization: Bearer <token>` header on `/api/kiwi/*` requests.

<Tabs>
  <Tab title="none (default)">
    No credentials. Use this for local development and trusted networks.

    ```bash
    curl http://localhost:3333/api/kiwi/tree
    ```
  </Tab>
  <Tab title="apikey">
    One shared key from `auth.api_key`. Values like `${KIWI_API_KEY}` are expanded from the environment.

    ```toml .kiwi/config.toml
    [auth]
    type = "apikey"
    api_key = "${KIWI_API_KEY}"
    ```

    ```bash
    curl http://localhost:3333/api/kiwi/tree \
      -H "Authorization: Bearer $KIWI_API_KEY"
    ```
  </Tab>
  <Tab title="perspace">
    A list of keys, each bound to an actor and optionally to a space, a scope, and a path prefix.

    ```toml .kiwi/config.toml
    [auth]
    type = "perspace"

    [[auth.api_keys]]
    key = "${ENG_KEY}"
    space = "engineering"
    actor = "agent:eng-bot"
    scope = "write"        # read | write | admin (default admin)
    prefix = "runbooks/"   # optional path restriction
    ```

    ```bash
    curl http://localhost:3333/api/kiwi/engineering/tree \
      -H "Authorization: Bearer $ENG_KEY"
    ```

    A `read` key can only send `GET` and `HEAD`. A key with `space` or `prefix` gets `403` for any `?path=` (or `/bulk` file path) outside that scope. The key's `actor` replaces whatever `X-Actor` the client sends.
  </Tab>
  <Tab title="oidc">
    A JWT from your identity provider, verified against `auth.oidc.issuer` and `auth.oidc.client_id`. The token's `email` claim (or `sub`) becomes the actor.

    ```bash
    curl http://localhost:3333/api/kiwi/tree \
      -H "Authorization: Bearer eyJhbGciOi..."
    ```
  </Tab>
</Tabs>

Send `SIGHUP` to the server process to reload `[auth]` from disk without a restart. See [Auth tokens](/guides/auth-tokens) for key management.

### What auth covers

| Route | When auth is on |
|---|---|
| `/api/kiwi/*` | Requires a valid bearer token. |
| `GET /api/kiwi/*` with `[space] visibility = "public"` | Open to anonymous reads. Writes still need a token. |
| `GET /file`, `/peek`, `/section` with `visibility = "unlisted"` | Open when `?path=` is set. Listing, tree, and search still need a token. |
| `/raw/*` | Needs a bearer token, a signed URL from [`GET /raw-sign`](/api/files#sign-a-raw-file-url), or a target that is already public. |
| `/llms.txt`, `/llms-full.txt` | Stay reachable without a token, but only list pages marked public or published (unless the space is public). |
| `/api/kiwi/public/*`, `/p/*` | Always anonymous. See [Publish](/api/publish). |
| `/health`, `/healthz`, `/readyz`, `/metrics`, `/api/docs`, `/api/openapi.json` | Always anonymous. |
| `/api/spaces`, `/api/init-templates` | Not checked by KiwiFS. Protect them at your proxy. |

<Warning>
`/mcp` only checks credentials in `apikey` mode, using the same key. With `perspace` or `oidc`, put `/mcp` behind your proxy's auth or disable it.
</Warning>

## Request headers

| Header | Purpose | Example |
|---|---|---|
| `Authorization` | Bearer token for any auth mode other than `none` | `Bearer kiwi_sk_abc123` |
| `X-Actor` | Commit author for writes. Ignored when `perspace` or `oidc` auth sets the actor. Defaults to `anonymous`. | `agent:my-agent` |
| `X-Provenance` | Adds a `derived-from` entry (`type`, `id`, `date`, `actor`) to the page's frontmatter on `PUT /file` and `POST /bulk`. Format is `type:id`. | `run:run-249` |
| `If-Match` | ETag the file must still have for the write to succeed | `"a1b2c3d4..."` |
| `If-None-Match` / `If-Modified-Since` | Conditional read on `GET /file`; returns `304` when unchanged | `"a1b2c3d4..."` |
| `X-Field-Manager` | Names the owner of frontmatter keys set by a [frontmatter patch](/api/files#patch-frontmatter) | `agent:triage` |
| `X-Kiwi-Space` | Target space on the shared `/api/kiwi/...` prefix | `engineering` |
| `X-Kiwi-Source` | Source label recorded with page-view analytics on `GET /file` | `slack-bot` |

<Tip>
Set `X-Actor` on every write when you use `none` or `apikey` auth. It becomes the git commit author, so you can trace which agent changed what with [blame](/api/versioning#blame).
</Tip>

## Optimistic concurrency

Every file read returns an `ETag` header: the quoted git blob hash of the content. Writes return the new ETag in both the `ETag` header and the JSON `etag` field.

Send that value back in `If-Match` to make a write conditional. If someone else changed the file since your read, the write is rejected with `409` and nothing is written.

```bash
# 1. Read and capture the ETag
ETAG=$(curl -sI 'http://localhost:3333/api/kiwi/file?path=concepts/auth.md' \
  | awk 'tolower($1)=="etag:" {print $2}' | tr -d '\r')

# 2. Write only if the file is unchanged
curl -X PUT 'http://localhost:3333/api/kiwi/file?path=concepts/auth.md' \
  -H "X-Actor: agent:updater" \
  -H "If-Match: $ETAG" \
  --data-binary @auth.md
```

```json 409 Conflict
{"error": "file modified since last read — re-fetch and retry"}
```

`If-Match` works on `PUT /file`, `PATCH /file`, and `PATCH /file/frontmatter`. For `POST /bulk`, set `if_match` per file; one mismatch fails the whole batch. Quotes around the ETag are optional.

## Errors

Errors return a JSON body with a single `error` field. Server-side failures (`5xx`) return a generic message; details go to the server log.

```json
{"error": "path is required"}
```

| Status | Meaning |
|---|---|
| `400` | Missing or invalid parameter, malformed JSON, or a path outside the knowledge root |
| `401` | Missing or invalid credentials |
| `403` | Token scope does not allow this method or path, or an invalid `/raw` signature |
| `404` | File, version, draft, view, or space not found |
| `409` | ETag mismatch, workflow transition denied, append-only file, frontmatter field owned by another manager, rename target exists, or draft merge conflict |
| `413` | Body too large (32 MB per file write, 110 MB per request) |
| `415` | Uploaded asset type is not in the allowlist |
| `422` | Write failed schema validation |
| `429` | Rate limit exceeded. Includes `Retry-After: 60`. |
| `501` | Optional feature is off (for example drafts) or unsupported by the versioning backend (blame, word diff) |
| `503` | Optional service unavailable (Dataview executor, vector search, claims, SSE subscriber cap) |
| `500` | Internal error |

## Pagination

There is no global pagination envelope. Endpoints that return long lists take their own parameters:

| Style | Endpoints | Parameters |
|---|---|---|
| Offset | [`GET /search`](/api/search), [`GET /query`](/api/metadata), [`GET /views/:name/execute`](/api/views#execute-a-view), [`GET /timeline`](/api/utilities) | `limit`, `offset`; DQL results include `total` and `has_more` |
| Cursor | [`GET /changes`](/api/versioning#change-feed) | `since` (a commit hash) and `limit`; pass the returned `last_seq` as the next `since` |

## Rate limiting

Rate limiting is off unless you set `requests_per_minute` above zero:

```toml .kiwi/config.toml
[server.rate_limit]
requests_per_minute = 300
burst_size = 50   # default 50
```

KiwiFS then applies a token bucket per bearer token (hashed) or per client IP for anonymous requests. `/health`, `/healthz`, `/readyz`, and `/metrics` are never limited. Over the limit, requests get `429` with `Retry-After: 60`.

## Health and metrics

Use these unauthenticated endpoints for container probes and monitoring.

<CodeGroup>
```bash Liveness
curl http://localhost:3333/healthz
```

```bash Readiness
curl http://localhost:3333/readyz
```

```bash Prometheus
curl http://localhost:3333/metrics
```
</CodeGroup>

**`GET /health`** always returns `{"status": "ok"}`. **`GET /healthz`** adds uptime and version:

```json
{"status": "ok", "uptime": "3h12m5s", "version": "0.19.78"}
```

**`GET /readyz`** checks storage and any enabled protocol servers (NFS, S3, WebDAV). It returns `200` with `status: "ready"`, or `503` with `status` set to `storage-unreachable` or `protocol-unhealthy`.

```json 503 Service Unavailable
{
  "status": "protocol-unhealthy",
  "protocols": {
    "nfs": {"enabled": true, "healthy": true, "port": 2049, "endpoint": "0.0.0.0:2049"},
    "webdav": {"enabled": true, "port": 3335, "endpoint": "0.0.0.0:3335", "error": "dial tcp 0.0.0.0:3335: connect: connection refused"}
  }
}
```

**`GET /metrics`** returns Prometheus text with `kiwi_build_info`, `kiwi_uptime_seconds`, `kiwi_sse_subscribers`, and `kiwi_janitor_issues` (after the first janitor scan). It does not export per-request counters; collect those at your proxy.
