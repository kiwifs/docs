Every write in KiwiFS becomes a git commit, authored by the request's actor. These endpoints read that history: list a file's commits, fetch an old version, diff two versions, see who wrote each line, or follow every change across the workspace.

All paths are relative to `http://localhost:3333/api/kiwi`. Blame and some diff modes depend on the versioning strategy; see [Versioning](/concepts/versioning).

## List file versions

Returns the commits that touched a file, newest first.

**`GET /versions`**

<ParamField query="path" type="string" required>
  File path.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/versions?path=concepts/auth.md'
```

<ResponseField name="path" type="string">The requested path.</ResponseField>
<ResponseField name="versions" type="object[]">
  <Expandable title="version">
    <ResponseField name="hash" type="string">Full commit hash.</ResponseField>
    <ResponseField name="date" type="string">Commit time, for example `2026-10-19 09:30:00 +0000`.</ResponseField>
    <ResponseField name="author" type="string">The actor that made the write.</ResponseField>
    <ResponseField name="message" type="string">Commit subject.</ResponseField>
  </Expandable>
</ResponseField>

```json Response
{
  "path": "concepts/auth.md",
  "versions": [
    {
      "hash": "e4f5a6b7c8d9e4f5a6b7c8d9e4f5a6b7c8d9e4f5",
      "date": "2026-10-19 09:30:00 +0000",
      "author": "agent:docs-writer",
      "message": "agent:docs-writer: concepts/auth.md"
    },
    {
      "hash": "a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5f6a1b2",
      "date": "2026-10-12 14:05:11 +0000",
      "author": "agent:importer",
      "message": "agent:importer: bulk write — 3 files"
    }
  ]
}
```

A file with no history returns an empty `versions` array.

## Read a past version

Returns a file's content as it was at a given commit.

**`GET /version`**

<ParamField query="path" type="string" required>
  File path.
</ParamField>
<ParamField query="version" type="string" required>
  Commit hash, full or abbreviated.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/version?path=concepts/auth.md&version=a1b2c3d'
```

```markdown Response
# Authentication

Original content from the first commit.
```

The body is `text/markdown`. Returns `404` if the file did not exist at that commit.

## Diff two versions

Returns a unified diff of one file between two commits, as plain text.

**`GET /diff`**

<ParamField query="path" type="string" required>
  File path.
</ParamField>
<ParamField query="from" type="string" required>
  Older commit hash.
</ParamField>
<ParamField query="to" type="string" required>
  Newer commit hash.
</ParamField>
<ParamField query="granularity" type="string" default="line">
  `line` for a unified diff or `word` for a word-level diff (`[-removed-]{+added+}` markers).
</ParamField>

<CodeGroup>
```bash Line diff
curl 'http://localhost:3333/api/kiwi/diff?path=concepts/auth.md&from=a1b2c3d&to=e4f5a6b'
```

```bash Word diff
curl 'http://localhost:3333/api/kiwi/diff?path=concepts/auth.md&from=a1b2c3d&to=e4f5a6b&granularity=word'
```
</CodeGroup>

```diff Response
diff --git a/concepts/auth.md b/concepts/auth.md
--- a/concepts/auth.md
+++ b/concepts/auth.md
@@ -1,3 +1,5 @@
 # Authentication

-Original content from the first commit.
+OAuth2 + JWT based authentication system.
+
+Supports refresh token rotation.
```

Returns `400` for any other `granularity` and `501` when the versioning strategy cannot produce a word diff.

## Blame

Returns the commit, author, and date that last changed each line of a file.

**`GET /blame`**

<ParamField query="path" type="string" required>
  File path.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/blame?path=concepts/auth.md'
```

<ResponseField name="path" type="string">The requested path.</ResponseField>
<ResponseField name="lines" type="object[]">
  <Expandable title="line">
    <ResponseField name="line" type="integer">1-based line number.</ResponseField>
    <ResponseField name="text" type="string">Line content.</ResponseField>
    <ResponseField name="hash" type="string">Commit that last changed the line.</ResponseField>
    <ResponseField name="author" type="string">Actor of that commit.</ResponseField>
    <ResponseField name="date" type="string">Commit time (RFC 3339).</ResponseField>
  </Expandable>
</ResponseField>

```json Response
{
  "path": "concepts/auth.md",
  "lines": [
    {"line": 1, "author": "agent:importer", "date": "2026-10-12T14:05:11Z", "hash": "a1b2c3d4...", "text": "# Authentication"},
    {"line": 3, "author": "agent:docs-writer", "date": "2026-10-19T09:30:00Z", "hash": "e4f5a6b7...", "text": "OAuth2 + JWT based authentication system."}
  ]
}
```

Blame needs the `git` strategy. Copy-on-write and `noop` strategies return `501`. An uncommitted file returns an empty `lines` array.

<Tip>
`author` is the `X-Actor` (or the key's actor) from the original write, so blame shows which agent wrote each section.
</Tip>

## Change feed

Lists recent commits across the whole workspace, newest first. Use it to sync external systems: poll with the last hash you saw, or long-poll to wait for the next change.

**`GET /changes`**

<ParamField query="since" type="string">
  Commit hash. Returns only commits after it. Omit to get the latest commits.
</ParamField>
<ParamField query="limit" type="integer" default="50">
  Maximum changes to return, up to 500.
</ParamField>
<ParamField query="feed" type="string">
  Set to `longpoll` to hold the request open until a change arrives when there are none yet.
</ParamField>
<ParamField query="timeout" type="string" default="30s">
  How long a long-poll waits, as a Go duration. Capped at `120s`. Returns an empty list on timeout.
</ParamField>

<CodeGroup>
```bash Latest changes
curl 'http://localhost:3333/api/kiwi/changes?limit=10'
```

```bash Wait for the next change
curl 'http://localhost:3333/api/kiwi/changes?since=e4f5a6b7c8d9&feed=longpoll&timeout=60s'
```
</CodeGroup>

<ResponseField name="changes" type="object[]">
  <Expandable title="change">
    <ResponseField name="seq" type="string">Commit hash.</ResponseField>
    <ResponseField name="path" type="string">Path changed. Empty for bulk writes.</ResponseField>
    <ResponseField name="action" type="string">`write`, `delete`, or `rename`.</ResponseField>
    <ResponseField name="actor" type="string">Commit author.</ResponseField>
    <ResponseField name="timestamp" type="string">Commit time (RFC 3339).</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="last_seq" type="string">Hash of the newest change in this response. Pass it as `since` next time. Empty when there are no changes.</ResponseField>

```json Response
{
  "changes": [
    {"seq": "e4f5a6b7...", "path": "concepts/billing.md", "action": "delete", "actor": "agent:cleanup", "timestamp": "2026-10-19T12:01:00Z"},
    {"seq": "d3e4f5a6...", "path": "concepts/auth.md", "action": "write", "actor": "agent:docs-writer", "timestamp": "2026-10-19T12:00:00Z"}
  ],
  "last_seq": "e4f5a6b7..."
}
```

Returns `400` with `unknown sequence` when `since` is not a known commit, and `503` if the long-poll subscriber limit is reached. For a push stream instead of polling, use [Server-Sent Events](/concepts/real-time-events).
