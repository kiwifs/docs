When KiwiFS runs with a **space manager**, space administration lives at `/api/spaces` (not under `/api/kiwi/`). Per-space file APIs remain at `/api/kiwi/...` or `/api/kiwi/{space}/...`.

See [Multi-space](/concepts/multi-space) for routing rules and `X-Kiwi-Space`.

## List spaces

```http
GET /api/spaces
```

```bash
curl -s 'http://localhost:3333/api/spaces'
```

```json
{
  "spaces": [
    {
      "name": "engineering",
      "root": "/data/eng-wiki",
      "fileCount": 1420,
      "sizeBytes": 45000000,
      "lastModified": "2026-05-02T10:00:00Z"
    }
  ]
}
```

## Get one space

```http
GET /api/spaces/:name
```

```bash
curl -s 'http://localhost:3333/api/spaces/engineering'
```

Returns **`404`** if the name is unknown.

## Create a space

```http
POST /api/spaces
Content-Type: application/json
```

```json
{
  "name": "research",
  "root": "/data/research-wiki"
}
```

```bash
curl -X POST 'http://localhost:3333/api/spaces' \
  -H 'Content-Type: application/json' \
  -d '{"name":"research","root":"/data/research-wiki"}'
```

Returns **`201`** with space metadata. Returns **`409`** if the name already exists. KiwiFS creates the root directory, initializes git and indexes, and persists the entry to `.kiwi/spaces.json`.

## Delete a space

```http
DELETE /api/spaces/:name
```

```bash
curl -X DELETE 'http://localhost:3333/api/spaces/research'
```

```json
{ "deleted": "research" }
```

Removes the space from the manager. Does not delete files on disk — clean up the `root` directory separately if needed.

## Auth

Protect `/api/spaces` in production. Creation and deletion are administrative operations. Per-space API keys (`auth.type = perspace`) apply to `/api/kiwi` routes after routing.
