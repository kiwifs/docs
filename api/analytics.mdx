## Health dashboard

Get an overview of your knowledge base health, link coverage, and engagement metrics.

<ParamField query="scope" type="string">
  Path prefix to scope results (for example `concepts/`).
</ParamField>
<ParamField query="stale_threshold" type="integer" default="30">
  Days without updates before a page counts as stale.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/analytics?scope=concepts/&stale_threshold=14'
```

```json
{
  "total_pages": 142,
  "total_words": 48200,
  "health": {
    "stale": { "count": 8, "paths": ["runbooks/deploy-v1.md"] },
    "orphans": { "count": 5, "paths": ["concepts/caching.md"] },
    "broken_links": { "count": 3, "paths": ["concepts/billing.md"] },
    "empty": { "count": 1, "paths": ["drafts/placeholder.md"] },
    "no_frontmatter": { "count": 12, "paths": ["notes/quick.md"] }
  },
  "coverage": {
    "pages_with_links": 120,
    "pages_without_links": 22,
    "avg_links_per_page": 4.2
  },
  "top_updated": [
    { "path": "concepts/auth.md", "updated_at": "2026-04-25T14:30:00Z" }
  ],
  "engagement": {
    "total_views": 1840,
    "top_viewed": [{ "path": "concepts/auth.md", "count": 312 }],
    "failed_searches": [{ "query": "oauth refresh", "count": 7, "search_type": "search" }]
  }
}
```

<ResponseField name="total_pages" type="integer">Total number of indexed pages.</ResponseField>
<ResponseField name="total_words" type="integer">Sum of word counts across pages.</ResponseField>
<ResponseField name="health" type="object">Stale, orphan, broken-link, empty, and no-frontmatter counts with sample paths.</ResponseField>
<ResponseField name="coverage" type="object">Link coverage statistics.</ResponseField>
<ResponseField name="top_updated" type="array">Most recently modified pages.</ResponseField>
<ResponseField name="engagement" type="object">Page view totals, top viewed pages, and top failed searches.</ResponseField>

<Note>
Analytics endpoints require the **sqlite** search backend. With `--search grep`, they return **501 Not Implemented**.
</Note>

## Page view tracking

Every `GET /api/kiwi/file` request for a knowledge file records a page view automatically. Bot user agents are excluded.

Attribute views to a client with the `source` query parameter or the `X-Kiwi-Source` header. When omitted, the source defaults to `api`. The web UI sends `ui`.

See [Files API — Read a file](/api/files#read-a-file).

## Page views

### Legacy aggregate

<ParamField query="top" type="integer" default="20">
  Maximum results to return.
</ParamField>
<ParamField query="path" type="string">
  Filter to a single page path.
</ParamField>
<ParamField query="since" type="string">
  Unix timestamp or RFC3339 date — only count views after this time.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/analytics/views?top=10&since=2026-04-01T00:00:00Z'
```

```json

  "since": 1743465600,
  "results": [{ "path": "concepts/auth.md", "count": 312 }]
}
```

### Time-series (v2)

<ParamField query="period" type="string" default="30d">
  Time window: `7d`, `30d`, or `90d`. Uses hourly buckets for ≤7d and daily buckets for longer periods.
</ParamField>
<ParamField query="path" type="string">
  Filter to a single page path.
</ParamField>
<ParamField query="source" type="string">
  Filter by view source (`ui`, `api`, `mcp`, etc.).
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/analytics/views/v2?period=7d&path=concepts/auth.md'
```

```json
{
  "period": "7d",
  "path": "concepts/auth.md",
  "time_series": [{ "timestamp": 1745539200, "count": 42 }],
  "top_pages": [{ "path": "concepts/auth.md", "count": 312 }]
}
```

### Content gaps

Failed searches surfaced as content-gap suggestions for agents.

<ParamField query="limit" type="integer" default="20">
  Maximum suggestions to return.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/analytics/content-gaps?limit=10'
```

Dismiss a content gap suggestion:

<ParamField body="query" type="string" required>
  Search query to dismiss.
</ParamField>
<ParamField body="search_type" type="string" default="search">
  Search type that produced the gap.
</ParamField>

```bash
curl -X POST 'http://localhost:3333/api/kiwi/analytics/content-gaps/dismiss' \
  -H 'Content-Type: application/json' \
  -d '{"query": "oauth refresh token", "search_type": "search"}'
```

```json
{ "dismissed": "oauth refresh token" }
```

## Memory report

Get an overview of your episodic memory structure — useful for agents that use the episode/merge pattern.

```http
GET /api/kiwi/memory/report
```

<ParamField query="episodes_prefix" type="string">
  Path prefix for episodes directory. Uses the configured default if omitted.
</ParamField>
<ParamField query="limit" type="integer">
  Paginate `episodic_files` and `unmerged` lists. When set, totals still reflect the full scan.
</ParamField>
<ParamField query="offset" type="integer">
  Skip this many entries before returning paginated lists.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/memory/report?limit=10&offset=0'
```

```json
{
  "episodic_count": 10,
  "total_episodic": 23,
  "total_unmerged": 8,
  "merged_from_refs": 15,
  "episodic_files": [
    { "path": "episodes/ep-001.md", "episode_id": "ep-001", "memory_kind": "episodic" }
  ],
  "unmerged": [
    { "path": "episodes/ep-012.md", "episode_id": "ep-012" }
  ],
  "warnings": ["Episode ep-012.md has no merge target"]
}
```

## Comments

Add, list, resolve, and delete inline comments on pages.

### List comments

<ParamField query="path" type="string" required>
  File path to list comments for.
</ParamField>

```bash
curl 'http://localhost:3333/api/kiwi/comments?path=concepts/auth.md'
```

```json
[
  {
    "id": "cmt_01",
    "path": "concepts/auth.md",
    "line": 15,
    "author": "agent:reviewer",
    "body": "Should this mention refresh tokens?",
    "resolved": false,
    "created": "2026-04-25T10:00:00Z"
  }
]
```

### Add a comment

```bash
curl -X POST 'http://localhost:3333/api/kiwi/comments?path=concepts/auth.md' \
  -H "Content-Type: application/json" \
  -H "X-Actor: agent:reviewer" \
  -d '{"line": 15, "body": "Should this mention refresh tokens?"}'
```

### Resolve a comment

```bash
curl -X PATCH 'http://localhost:3333/api/kiwi/comments/cmt_01' \
  -H "Content-Type: application/json" \
  -d '{"resolved": true}'
```

### Delete a comment

```bash
curl -X DELETE 'http://localhost:3333/api/kiwi/comments/cmt_01'
```

## Sharing

Create and manage share links for pages.

### Create a share link

```bash
curl -X POST 'http://localhost:3333/api/kiwi/share' \
  -H "Content-Type: application/json" \
  -H "X-Actor: agent:sharer" \
  -d '{"path": "concepts/auth.md", "expiresIn": "168h", "password": "optional-secret"}'
```

`expiresIn` is a Go duration string (`168h` for seven days). Omit it for links that never expire.

```json
{
  "id": "a1b2c3d4",
  "path": "concepts/auth.md",
  "token": "<opaque-token>",
  "expiresAt": "2026-05-09T14:30:00Z",
  "createdBy": "agent:sharer",
  "createdAt": "2026-05-02T14:30:00Z",
  "viewCount": 0
}
```

Readers open `GET /api/kiwi/public/:token` (see [Utilities](/api/utilities#public-routes)).

### List share links

```bash
curl 'http://localhost:3333/api/kiwi/share?path=concepts/auth.md'
```

`path` is **required** — the handler returns every active link for that page.

### Revoke a share link

```bash
curl -X DELETE 'http://localhost:3333/api/kiwi/share/a1b2c3d4'
```

Returns JSON `{ "revoked": "<id>" }` using the share **`id`** field (not the long `token`).

## Real-time events (SSE)

Subscribe to a Server-Sent Events stream that emits events on every write and delete. Use this for real-time UI updates or external integrations.

```bash
curl -N 'http://localhost:3333/api/kiwi/events'
```

```
event: write
data: {"path":"concepts/auth.md","actor":"agent:docs-writer","timestamp":"2026-04-25T14:30:00Z"}

event: delete
data: {"path":"concepts/old-page.md","actor":"agent:cleanup","timestamp":"2026-04-25T14:31:00Z"}

event: write
data: {"path":"concepts/billing.md","actor":"agent:importer","timestamp":"2026-04-25T14:32:00Z"}
```

<Note>
The SSE connection stays open indefinitely. Use `curl -N` (no-buffer) to see events as they arrive. In production, implement reconnection logic with the `Last-Event-ID` header.
</Note>

### Event types

| Event | Trigger |
|---|---|
| `write` | A file was created or updated |
| `delete` | A file was deleted |
| `bulk` | A bulk write completed |
| `import` | An import completed |
