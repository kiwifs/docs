title: "Document export"
description: "Render markdown to PDF, HTML, slides, or a static site via REST, CLI, or MCP."
icon: "file-pdf"
---

Beyond JSONL and CSV, KiwiFS can **render** markdown into deliverable formats using Pandoc, Marp, and MkDocs tooling (typically inside the Docker image).

<Tabs>
  <Tab title="REST">
    ```bash
    curl -X POST 'http://localhost:3333/api/kiwi/export/document' \
      -H 'Content-Type: application/json' \
      -d '{"format":"pdf","path":"pages/report.md","theme":"paper"}' \
      -o report.pdf
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    kiwifs export --format pdf --path pages/report.md --output report.pdf --theme paper
    ```
  </Tab>
  <Tab title="MCP">
    Call **`kiwi_export_document`** with the same options as the REST body.
  </Tab>
</Tabs>

## Endpoint

```http
POST /api/kiwi/export/document
Content-Type: application/json
```

## Request body

<ParamField body="format" type="string" required>
  Output format: `pdf`, `html`, `slides`, or `site`.
</ParamField>

<ParamField body="path" type="string" required>
  File or directory under the knowledge root.
</ParamField>

<ParamField body="theme" type="string">
  Built-in theme: `paper`, `modern`, `minimal`, `dark`, or `presentation`. You can also place custom templates in `.kiwi/themes/`.
</ParamField>

<ParamField body="self_contained" type="boolean" default="false">
  Produce a single-file HTML or PDF with embedded assets.
</ParamField>

<ParamField body="bibliography" type="string">
  Path to a `.bib` or `.json` bibliography file for citations.
</ParamField>

<ParamField body="csl_style" type="string">
  Citation style: `apa`, `ieee`, `chicago`, `vancouver`, or `harvard`.
</ParamField>

<ParamField body="crossref" type="boolean" default="false">
  Enable cross-reference processing for figures, tables, and equations.
</ParamField>

<ParamField body="pdf_engine" type="string">
  PDF engine: `typst` or `xelatex`. Auto-detects when omitted.
</ParamField>

<ParamField body="slide_format" type="string" default="html">
  Slide output format: `html`, `pdf`, or `pptx` (Marp).
</ParamField>

<ParamField body="site_name" type="string">
  Static site title (`site` format).
</ParamField>

<ParamField body="site_url" type="string">
  Canonical site URL for MkDocs export.
</ParamField>

<ParamField body="repo_url" type="string">
  Repository URL for edit-on-GitHub style links.
</ParamField>

## Examples

<CodeGroup>
```bash PDF single page
curl -X POST 'http://localhost:3333/api/kiwi/export/document' \
  -H 'Content-Type: application/json' \
  -d '{"format":"pdf","path":"pages/report.md","theme":"paper"}' \
  -o report.pdf
```

```bash HTML bundle
curl -X POST 'http://localhost:3333/api/kiwi/export/document' \
  -H 'Content-Type: application/json' \
  -d '{"format":"html","path":"concepts/","self_contained":true}' \
  -o site.html
```

```bash Slide deck
curl -X POST 'http://localhost:3333/api/kiwi/export/document' \
  -H 'Content-Type: application/json' \
  -d '{"format":"slides","path":"talks/intro.md","slide_format":"pdf"}' \
  -o intro.pdf
```

```bash CLI PDF export
kiwifs export --format pdf --path docs/report.md --output report.pdf --theme modern --crossref
```
</CodeGroup>

The response streams the rendered artifact with an appropriate `Content-Type`. Large exports may take up to **five minutes** server-side.

<Warning>
Document export requires `--path`. Data-only formats (`jsonl`, `csv`, `parquet`) do not need it.
</Warning>

## Docker requirement

PDF and site generation depend on external tools bundled in the official Docker image. Bare-metal installs may need those dependencies installed separately or export via Docker.
