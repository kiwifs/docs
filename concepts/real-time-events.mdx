KiwiFS broadcasts every change in a space over **Server-Sent Events (SSE)** at `GET /api/kiwi/events`. The web UI uses this stream to refresh the file tree, open pages, canvases, and boards as soon as anyone edits them. You can subscribe the same way to keep a cache, dashboard, or agent in sync.

SSE is the only real-time transport; there is no WebSocket endpoint. To push changes to a service that cannot hold a connection open, use [webhooks](/concepts/webhooks).

## Subscribe

```bash Terminal
curl -N 'http://localhost:3333/api/kiwi/events' \
  -H 'Authorization: Bearer kiwi_sk_...'
```

```text Stream
event: write
data: {"op":"write","path":"concepts/auth.md","actor":"agent:docs-writer","etag":"5d41402abc4b2a76"}

event: delete
data: {"op":"delete","path":"drafts/old.md","actor":"alice"}

event: bulk
data: {"op":"bulk","paths":["notes/a.md","notes/b.md"],"actor":"agent:importer"}

:keep-alive

event: comment.add
data: {"op":"comment.add","path":"concepts/auth.md","actor":"bob"}
```

Each message has an `event:` line naming the event type and a `data:` line of JSON. A `:keep-alive` comment arrives every 15 seconds so proxies do not close an idle stream.

<CodeGroup>
```javascript Browser
const events = new EventSource("/api/kiwi/events");

events.addEventListener("write", (e) => {
  const { path, etag, actor } = JSON.parse(e.data);
  console.log(`${actor} wrote ${path} (${etag})`);
});

events.addEventListener("delete", (e) => {
  console.log("deleted", JSON.parse(e.data).path);
});
```

```python Python
import json, requests

with requests.get("http://localhost:3333/api/kiwi/events",
                  headers={"Authorization": "Bearer kiwi_sk_..."}, stream=True) as r:
    event = None
    for line in r.iter_lines(decode_unicode=True):
        if line.startswith("event: "):
            event = line[7:]
        elif line.startswith("data: "):
            print(event, json.loads(line[6:]))
```
</CodeGroup>

## Event types

| Event | Fires when | Payload fields |
| --- | --- | --- |
| `write` | A file is created or updated, including renames (new path), canvas saves, frontmatter patches, and edits made directly on disk | `path`, `actor`, `etag` |
| `delete` | A file is deleted, or renamed away from its old path | `path`, `actor` |
| `bulk` | A bulk write (`POST /api/kiwi/bulk`) commits. Imports write file by file and send `write` events. | `paths`, `actor` |
| `rollback` | A bulk write fails to commit and its files are restored | `paths`, `actor` |
| `comment.add`, `comment.delete`, `comment.resolve` | A comment on a page changes | `path`, `actor` |
| `janitor` | A scheduled janitor scan finishes | `actor` (`scheduler`) and `extra` with `status`, `scanned`, `issues`, `errors`, `warnings`, and `duration_ms` |

Every payload also repeats the event type as `op`. Events carry no file content. Compare `etag` with what you hold, and re-read the file with `GET /api/kiwi/file` when it differs.

## When events fire

File events are sent after the full write pipeline: storage, git commit, index update, then broadcast. When you receive `write`, the new content is already readable and searchable.

The pipeline is shared by every protocol, so writes over REST, MCP, NFS, S3, WebDAV, and FUSE, as well as edits made in an editor on the server's disk, all produce the same events.

## Client guidance

- **Reconnect.** The stream stays open until either side closes it. Reconnect with backoff when it drops. Browsers' `EventSource` does this for you.
- **Resync after a gap.** Events have no IDs, and KiwiFS ignores `Last-Event-ID`. After reconnecting, catch up with `GET /api/kiwi/changes` or by re-reading the files you care about.
- **Keep up.** Each subscriber has a small buffer. A client that reads too slowly misses events instead of slowing the server.
- **Authenticate** like any other `/api/kiwi` route. The browser `EventSource` API cannot send an `Authorization` header, so when auth is on, browser clients need a same-origin proxy that adds it.
- **Limits.** A space accepts up to 256 concurrent subscribers. Beyond that, the endpoint returns `503`.
- **Spaces.** Each space has its own stream. Subscribe to `/api/kiwi/{space}/events`, or send `X-Kiwi-Space`. See [Multi-space](/concepts/multi-space).
