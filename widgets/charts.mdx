Two kinds of chart blocks exist:

- **Typed fences** (`plot`, `bars`, `numberline`, `plane`, `timeline`) draw an exact picture you can step through and annotate. They follow the shared rules for [steps, meta strings, playback, and validation](/concepts/widgets#writing-a-typed-fence).
- **Dashboard blocks** (`kiwi-chart`, `kiwi-progress`) draw a standard chart from rows of data. `kiwi-chart` can pull its rows from a DQL query, so the chart stays current as pages change.

## plot

An x-y plot: complexity curves, latency against load, convergence, the predicate curve of a binary search. A series takes `points`, or an `expr` formula in `x` whose free names come from `bind`, which can change per step to sweep a parameter.

A bare `plot` fence renders when its body has `series`. Also spelled `kiwi-plot`, `widget:plot`, `chart-xy`.

````markdown
```plot id=predicate caption="Binary search on the answer: the predicate flips once"
xLabel: capacity
yLabel: days needed
series:
  - label: days(capacity)
    points: [{x: 10, y: 15}, {x: 15, y: 10}, {x: 20, y: 7}, {x: 25, y: 6}, {x: 30, y: 5}]
guides:
  - {y: 7, label: "budget"}
steps:
  - note: "Too slow: 15 days exceeds the 7-day budget"
    marks: [{x: 10, y: 15, label: "lo"}]
  - note: "Fast enough — search left for a smaller capacity"
    marks: [{x: 20, y: 7, label: "mid"}]
  - note: "The smallest capacity that fits the budget is 20"
    marks: [{x: 20, y: 7, label: "answer"}]
    breakpoint: true
```
````

## bars

Columns in value space: histograms, latency distributions, sorting passes. `guides` draws horizontal reference lines such as an SLO, and `overlays` draws value-space rectangles such as trapped water or a chosen rectangle.

A bare `bars` fence renders when its body has `values`. Also spelled `kiwi-bars`, `widget:bars`, `histogram`, `barchart`.

````markdown
```bars id=rain caption="Trapping rain water"
values: [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
steps:
  - note: "Water sits wherever both sides are higher"
    overlays: [{startIndex: 2, toValue: 1, label: "1"}]
    activeIndices: [1, 3]
  - note: "The big basin between 3 and 7 holds four units"
    overlays:
      - {startIndex: 2, toValue: 1}
      - {startIndex: 4, endIndex: 6, toValue: 2, label: "4"}
    activeIndices: [3, 7]
  - note: "Total: 6"
    overlays:
      - {startIndex: 2, toValue: 1}
      - {startIndex: 4, endIndex: 6, toValue: 2}
      - {startIndex: 9, toValue: 2, label: "1"}
```
````

## numberline

A single value axis: inequalities, intervals, thresholds, binary-search buckets. Closed endpoints are filled and open ones hollow. `predicate` shades wherever a formula in `x` is true.

A bare `numberline` fence renders when its body has `min` or `max` or `xRange`. Also spelled `kiwi-numberline`, `widget:numberline`, `number-line`, `kiwi-number-line`.

````markdown
```numberline id=budget caption="Where this quarter's error budget stands"
label: "% of error budget spent"
min: 0
max: 100
step: 20
intervals:
  - {from: 0, to: 50, label: ship freely}
  - {from: 50, to: 85, label: ship with review}
  - {from: 85, to: 100, label: freeze}
marks: [{at: 85, label: freeze line}]
pointers: [{at: 62, label: now}]
```
````

| `xRange` | array of number | `[min, max]` or `[min, max, step]`, an alias for the three keys. |

</Accordion>

## plane

A coordinate plane in data units: geometry, sweep lines, convex hulls, vectors, tile maps. It draws what you give it, so the algorithm lives in the steps. Segment and polygon ends can name a point `id`.

A bare `plane` fence renders when its body has `points` or `segments` or `polygons` or `circles` or `vectors` or `regions`. Also spelled `kiwi-plane`, `widget:plane`, `geometry`.

````markdown
```plane id=hull caption="Andrew's monotone chain, lower hull"
xMin: 0
xMax: 10
yMin: 0
yMax: 8
points:
  - {id: a, x: 1, y: 1, label: a}
  - {id: b, x: 3, y: 4, label: b}
  - {id: c, x: 5, y: 2, label: c}
  - {id: d, x: 8, y: 6, label: d}
  - {id: e, x: 9, y: 2, label: e}
steps:
  - note: "Sort by x, start the lower hull with a and b"
    polygons: [{points: [a, b], open: true, id: hull}]
    activeIds: [a, b]
  - note: "a→b→c turns clockwise, so b is not on the hull — pop it"
    polygons: [{points: [a, b, c], open: true, id: hull}]
    activeIds: [b]
  - note: "Lower hull is a, c, e"
    polygons: [{points: [a, c, e], open: true, id: hull}]
    highlightIds: [hull]
    dimIds: [b, d]
```
````

## timeline

Spans on a shared axis with named lanes and causal arrows: scheduling, lock handoffs, happens-before, incident timelines. A span with `state: blocked` or `state: waiting` draws hatched, so waiting reads differently from working.

A bare `timeline` fence renders when its body has `intervals`. Also spelled `kiwi-timeline`, `widget:timeline`, `gantt`, `schedule`.

````markdown
```timeline id=lock caption="T2 blocks on the row lock T1 holds"
lanes: [T1, T2]
hoverPredecessors: true
intervals:
  - {id: t1run, lane: T1, start: 0, end: 4, label: "UPDATE", state: holding}
  - {id: t1commit, lane: T1, start: 4, end: 5, label: COMMIT, state: running}
  - {id: t2wait, lane: T2, start: 2, end: 5, label: "waiting for lock", state: blocked}
  - {id: t2run, lane: T2, start: 5, end: 8, label: "UPDATE", state: holding}
links:
  - {from: t1commit, to: t2run, label: "lock released"}
steps:
  - note: "T1 takes the row lock"
    activeIds: [t1run]
  - note: "T2's UPDATE blocks — hatched, because it is doing no work"
    activeIds: [t2wait]
  - note: "T1 commits and T2 is woken"
    activeIds: [t1commit, t2run]
```
````

<Accordion title="All 21 keys">

| Key | Type | Description |
| --- | --- | --- |
| `intervals` | array of object | **Required.** `{start, end, id?, label?, lane?, state?, color?}`. `start === end` draws a point event. `state` of "blocked" or "waiting" draws hatched. |
| `activeColor` | string | Primary highlight color. Fixed across steps. |
| `activeIds` | array or number or string | Span ids active this step. |
| `ariaLabel` | string | Accessible name. Defaults to a summary derived from the data. Fixed across steps. |
| `dimIds` | array or number or string | Dimmed span ids. |
| `highlightColor` | string | Secondary highlight color. Fixed across steps. |
| `highlightIds` | array or number or string | Secondary-highlighted span ids. |
| `hoverPredecessors` | boolean | Hovering a span lights the happens-before cone behind it. Fixed across steps. |
| `laneHeight` | number | Row height, px. Default 26. Fixed across steps. |
| `lanes` | array of string | Named lanes in draw order, labelled in the gutter — `thread A` above `thread B`. |
| `links` | array of object | Causal arrows between spans: `{from, to, label?, dashed?}` — happens-before, woken by, lock handoff. |
| `marks` | array of object | Extra vertical marks: query points, event coordinates. `{at, label?, color?}`. |
| `max` | number | Right end of the axis. |
| `min` | number | Left end of the axis. Defaults to the data extent. |
| `props` | any | Escape hatch for a widget prop whose name collides with a reserved key. |
| `showAxis` | boolean | Draw the axis. Default true. Fixed across steps. |
| `showLegend` | boolean | Draw a legend for the `state` values in use. Fixed across steps. |
| `sweep` | number | Position of the sweep cursor. |
| `sweepLabel` | string | Caption beside the sweep cursor — usually the running counter. |
| `ticks` | array of number | Values to label on the axis. |
| `width` | number | Canvas width, px. Fixed across steps. |

</Accordion>

## kiwi-chart

Bar, line, area, pie, radar, and scatter charts from inline rows, rendered with Recharts.

````markdown
```kiwi-chart
type: bar
title: Weekly deploys
xKey: week
data:
  - week: W40
    deploys: 21
    rollbacks: 2
  - week: W41
    deploys: 34
    rollbacks: 1
  - week: W42
    deploys: 28
    rollbacks: 3
series:
  - key: deploys
    color: "#22c55e"
  - key: rollbacks
    color: "#ef4444"
legend: true
```
````

Without `series`, every numeric column in the first row becomes a series. Without `xKey`, bar, line, and area charts draw no category axis, so name it.

To chart live data, give a `query:` instead of `data:`. The first non-numeric result column becomes the x axis and every numeric column becomes a series. Inline `data` still renders if the query fails.

````markdown
```kiwi-chart
type: bar
title: Open incidents by service
query: |
  TABLE title, open_incidents FROM "services" SORT open_incidents DESC
```
````

<Accordion title="kiwi-chart keys">

| Key | Type | Description |
| --- | --- | --- |
| `type` | `bar` \| `line` \| `area` \| `pie` \| `radar` \| `scatter` | Chart type. Default `bar`. |
| `title` | string | Heading above the chart. |
| `data` | array of object | Rows. Required unless `query` is set. |
| `query` | string | DQL query whose result rows replace `data`. Use a `\|` block for multi-line queries. |
| `xKey` | string | Column for the category axis. Pie and radar charts fall back to the first text column; scatter to `x`. |
| `yKey` | string | Scatter only: column for y values. |
| `series` | array of object | `{key, color?, name?, stackId?}` per plotted column. |
| `stacked` | boolean | Stack the series. |
| `legend` | boolean | Show a legend. |
| `grid` | boolean | Show grid lines. |
| `height` | number | Chart height in px. Default 300. |
| `colors` | array of string | Palette for inferred series. |

</Accordion>

The body can also be JSON with the same keys.

## kiwi-progress

Progress bars or radial gauges, one per item.

````markdown
```kiwi-progress
type: bar
title: Q4 migration
items:
  - label: Backend services
    value: 85
  - label: Web UI
    value: 60
  - label: Data backfill
    value: 3
    max: 12
```
````

<Accordion title="kiwi-progress keys">

| Key | Type | Description |
| --- | --- | --- |
| `type` | `bar` \| `gauge` | Horizontal bars or radial gauges. Default `bar`. |
| `title` | string | Heading above the items. |
| `items` | array of object | `{label, value, max?, color?}`. `max` defaults to 100. Without `color`, the fill goes from red to green as the item nears `max`. |
| `showPercent` | boolean | Show the percentage. Default true. |
| `animated` | boolean | Animate the fill. Default true. |

</Accordion>
