KiwiFS is a **knowledge server** that gives you Obsidian's file-first philosophy with a web UI, agent-native filesystem access, Git versioning, and full-text + vector search — all in a single Go binary.

```bash
curl -fsSL https://raw.githubusercontent.com/kiwifs/kiwifs/main/install.sh | sh
kiwifs init ./knowledge && kiwifs serve --root ./knowledge
# Open http://localhost:3333
```

## Why KiwiFS?

Every agent memory project gives you **storage** — a database table, a vector index, a key-value store. But storage is only one layer. In practice you need:

- **An agent interface** — agents already know `cat`, `grep`, `ls`. They don't need a custom SDK.
- **A human interface** — someone has to review what the agent wrote. A wiki UI, not pgAdmin.
- **An audit trail** — who changed what, when, and why. Cryptographic, not "trust the vendor."
- **Search** — full-text (BM25) and semantic (vector), over the same files.

No existing tool does all four. KiwiFS is the full stack.

## How it works

```
AGENT                              HUMAN
─────                              ─────
cat /kiwi/concepts/auth.md         Web UI (wiki links,
grep -r "timeout" /kiwi/            graph view, search)
echo "# Report" > /kiwi/r.md

       ↕                                ↕
     ┌──────────────────────────────────────┐
     │       Markdown files in folders      │
     │       (the single source of truth)   │
     └──────────────────────────────────────┘
       ↕                ↕              ↕
    Git versioning   FTS5 + vector   SSE events
    (audit trail)    (search index)  (live updates)
```

## Who this is for

- **AI agent builders** — Give your agent persistent, searchable memory it accesses with `cat`. Users browse the same files in a web UI with wiki links and graph view.
- **Teams replacing Confluence / Notion** — Obsidian's file-first philosophy with a web UI. `git clone` your entire wiki. Self-hosted.
- **Compliance-heavy industries** — Every change is a git commit with SHA-1 hash chain. `git blame` for per-line attribution.
- **DevOps / platform teams** — Runbooks that agents update after every incident. Humans review in the UI.
